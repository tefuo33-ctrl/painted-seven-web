# 3D-модели Painted Seven

Модели делаются скриптами Python для Blender, поэтому любую можно пересоздать одной командой.

| Папка | Что там |
|---|---|
| `scripts/` | скрипты Blender (`bpy`) — исходник каждой модели |
| `blend/` | файлы Blender — можно открыть и поправить руками |
| `export/` | `.glb` для игры (three.js сейчас, Godot потом) |
| `previews/` | PNG-превью |

## Пересоздать модель

Blender установлен через Steam (версия 5.3). Из корня репозитория (Git Bash):

```bash
"/c/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe" --background --python assets/3d/scripts/table_with_lamp.py
```

Размеры и цвета — в блоке `НАСТРОЙКИ` в начале каждого скрипта. Единицы — метры, пол на высоте 0.

## Модели

| Модель | Скрипт | Что внутри |
|---|---|---|
| Стол с лампой | `table_with_lamp.py` | круглый стол (сукно, золотой кант, борт, тумба), абажур со шнуром, тёплый spot-свет, 3 карты |
| Тестовый куб | `test_cube.py` | проверка, что Blender запускается из скрипта |

Все модели здесь сделаны с нуля, без чужих ассетов. Чужие ассеты (CC0 и т. п.) записывать в `assets/LICENSES.md`.
