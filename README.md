# Расписной покер — Painted Seven (веб-прототип)

Карточная игра на взятки: вы против трёх ботов. Колода 36 карт, 28 раундов,
семёрка пик — джокер. Правила и все допущения — в [RULES.md](RULES.md).

## Запуск

Нужен [Node.js](https://nodejs.org) (версия LTS).

```bash
npm install
```

```bash
npm run dev
```

Игра откроется в браузере (обычно `http://localhost:5173`).

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | запускает автотесты правил |
| `npm run build` | проверяет типы и собирает игру в папку `dist/` |
| `npm run preview` | показывает собранную версию из `dist/` |

## Структура

```
src/
  engine/        Правила игры. Чистый TypeScript: нет DOM, нет браузера.
    cards.ts       карты, масти, колода, джокер
    deck.ts        тасовка (по seed), срез, раздача
    rounds.ts      последовательность 28 раундов и режимы
    rules.ts       главное правило: легальные ходы, победитель взятки, джокер
    scoring.ts     подсчёт очков
    settings.ts    настройки правил (всё спорное — здесь)
    game.ts        ход партии: раздача → заказ → взятки → таблица
    index.ts       единая точка входа в движок
  ai/
    bot.ts         боты: заказ и выбор карты
  ui/            Интерфейс для браузера.
    app.ts         клики, ходы ботов по таймеру, сохранение партии
    view.ts        отрисовка экрана (HTML-строки)
    style.css      стили: телефон и компьютер
  main.ts        точка входа веб-версии
tests/           Автотесты (Vitest). Номера T-NN — сценарии из заметок.
RULES.md         Правила и допущения
```

## Как это устроено

- **Движок отдельно от интерфейса.** `src/engine` ничего не знает про экран.
  Состояние партии (`GameState`) — обычный объект: его можно сохранить в JSON,
  отправить по сети или показать в другом интерфейсе.
- **Интерфейс только показывает и передаёт действия.** Все проверки
  («можно ли пойти этой картой») делает движок.
- **Партия сохраняется** в браузере автоматически, её можно продолжить из меню.

## Планы (пока не сделано, архитектура заложена)

- **Телефон (Capacitor).** Capacitor упаковывает папку `dist/` в приложение для Android и iOS.
  Сборка уже использует относительные пути (`base: './'` в `vite.config.ts`), вёрстка — под вертикальный экран.
- **Компьютер (Tauri или Electron).** То же самое: оболочка открывает `dist/index.html`.
- **Онлайн с друзьями.** Движок работает через действия (`placeBid`, `playCard`, …) над
  сериализуемым состоянием. На сервере будет тот же `src/engine`, а клиент будет
  отправлять действия вместо того, чтобы применять их сам. Боты заменяются людьми без изменения правил.
