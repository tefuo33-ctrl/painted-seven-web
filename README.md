# Расписной покер — Painted Seven

Карточная игра на взятки в 3D прямо в браузере: терраса у моря на закате, стол,
четыре игрока в костюмах и тёмных очках. Колода 36 карт, 28 раундов, семёрка пик — джокер.
Можно играть одному против ботов или с друзьями по ссылке.

Правила и все допущения — в [RULES.md](RULES.md).

**Играть в браузере:** https://tefuo33-ctrl.github.io/painted-seven-web/

## Как запустить на своём компьютере

Нужен [Node.js](https://nodejs.org) (версия LTS). Все команды выполняются в папке проекта.

Один раз установить зависимости:

```bash
npm install
```

Запустить игру (откроется в браузере, обычно `http://localhost:5173`):

```bash
npm run dev
```

Чтобы работала **игра с друзьями**, во втором окне терминала запустите сервер:

```bash
npm run server
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | запускает автотесты правил и сервера |
| `npm run build` | проверяет типы и собирает игру в папку `dist/` |
| `npm run preview` | показывает собранную версию из `dist/` |

## Как выложить в интернет

Игра состоит из двух частей, и выкладываются они в разные места.

### 1. Сама игра (страница) — GitHub Pages

Уже настроено: каждый коммит в ветку `main` автоматически собирается и публикуется
(файл `.github/workflows/ci.yml`). Одиночная игра против ботов работает без сервера.

### 2. Сервер для игры с друзьями — Render

GitHub Pages умеет отдавать только готовые страницы, а для игры с друзьями нужна программа,
которая работает постоянно и ведёт партии. Её можно бесплатно разместить на [render.com](https://render.com):

1. Зарегистрируйтесь на render.com (удобно — через аккаунт GitHub).
2. Нажмите **New → Web Service** и выберите репозиторий `painted-seven-web`.
3. Заполните поля:
   - **Branch:** `main`
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm run server`
   - **Instance Type:** Free
4. Нажмите **Create Web Service** и дождитесь надписи «Live». Вверху появится адрес вида
   `https://painted-seven-web.onrender.com`. Откройте его — должно быть написано «сервер работает».
5. Сообщите этот адрес игре: впишите его в `src/net/client.ts`, в строку `PUBLIC_SERVER_URL`,
   заменив `https://` на `wss://` (например, `wss://painted-seven-web.onrender.com`), и сделайте коммит в `main`.

Сейчас сервер уже работает по адресу `https://painted-seven-web.onrender.com` и вписан в игру.
Render сам обновляет его при каждом коммите в `main`.

Особенность бесплатного тарифа Render: если сервером 15 минут никто не пользуется, он «засыпает»,
и первое подключение после этого занимает около минуты.

## Структура

```
src/
  engine/        Правила игры. Чистый TypeScript: нет экрана, нет 3D.
    cards.ts       карты, масти, колода, джокер
    deck.ts        тасовка (по seed), раздача
    rounds.ts      последовательность 28 раундов и режимы
    rules.ts       главное правило: легальные ходы, победитель взятки, джокер
    scoring.ts     подсчёт очков
    settings.ts    настройки правил (всё спорное — здесь)
    game.ts        ход партии: раздача → заказ → взятки → таблица
  ai/bot.ts      боты: заказ и выбор карты
  shared/        данные, общие для браузера и сервера
    names.ts       имена ботов (190 мужских, 185 женских)
    skin.ts        внешний вид персонажей: палитры костюмов, галстуков, рубашек
  net/
    protocol.ts    сообщения между браузером и сервером, «вид игрока» без чужих карт
    client.ts      подключение браузера к серверу
  three/         3D-сцена (Three.js). Все модели и текстуры созданы кодом.
    gfx.ts         стиль: плоские грани, дрожание вершин, текстуры без сглаживания, настройки
    stage.ts       рендер в низком разрешении, камера, блум и виньетка
    location.ts    терраса, море, закат, фонарь, городок
    table.ts       стол и кресла
    cardAtlas.ts   все карты на одной текстуре: масти, ранги, портреты, рубашка
    card3d.ts      одна 3D-карта и её полёт
    tableView.ts   раскладка карт: колода, руки, взятка, козырь, раздача
    turnMarker.ts  подсветка «чей ход»: луч и сектор стола
    character.ts   персонажи: головы, костюмы, анимации
    players.ts     соперники за столом и персонаж в «Гардеробе»
  ui/            Интерфейс поверх сцены.
    app.ts         нажатия, ходы ботов, игра с друзьями, сохранение
    view.ts        меню, таблички, окна, таблица очков (HTML)
    sound.ts       звук, синтезируется кодом
    profile.ts     имя и внешний вид игрока
    style.css      стили: телефон и компьютер
  main.ts        точка входа
server/
  index.ts       сервер: комнаты по коду, WebSocket
  room.ts        одна комната: места, боты, ход партии
tests/           Автотесты (Vitest): правила, джокер, очки, партии целиком, сервер
RULES.md         Правила и допущения
```

## Как это устроено

- **Правила отдельно от картинки.** `src/engine` не знает ни про 3D, ни про браузер. Один и тот же код
  работает в одиночной игре, на сервере и в тестах.
- **В игре с друзьями правила считает сервер.** Браузер получает только «вид игрока»: свои карты и то,
  что видно всем. Чужие карты по сети не передаются, подсмотреть их нельзя.
- **Никаких скачанных моделей и картинок.** Сцена, персонажи, карты и звуки эффектов создаются кодом.
  Единственный файл — музыка главного меню (`public/audio/soundtrack.mp3`, саундтрек Тима).
- **Три языка.** Русский, немецкий и английский: все тексты в `src/i18n`, выбор запоминается.
  На немецком и английском имена игроков пишутся латиницей.
- **Настройки.** Язык, музыка и эффекты (вкл/выкл и громкость 0–100), качество и свечение —
  в меню «Настройки», всё сохраняется в браузере.
- **Камера.** Тянуть мышью — осмотреться (вверх-вниз ограничено), колесо или два пальца — приблизить,
  двойной щелчок — рассмотреть предмет, кнопка «Вернуть вид» — назад за стол.

## Планы

- Приложение для телефона (Capacitor) и компьютера (Tauri) из той же сборки `dist/`.
- Пиксельный шрифт интерфейса.
- Новые, более детальные персонажи и окружение (сейчас — временные модели).
